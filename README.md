# 🎓 Smart Attendance System using Face Recognition

## 📌 Project Overview
This project is a Face Recognition-based Attendance System built using Machine Learning and Computer Vision.

## 🎯 Objective
To automate attendance using real-time face recognition and eliminate proxy attendance.

## 🛠 Technologies Used
- Python
- OpenCV
- face_recognition
- SQLite
- Streamlit

## ⚙️ Features
- User Login & Registration
- Face Recognition Attendance
- IN / OUT System
- Dashboard with Analytics
- Export to Excel

## 🚀 How to Run

```bash
pip install -r requirements.txt
python collect_dataset.py
python generate_embeddings.py
streamlit run dashboard.py
